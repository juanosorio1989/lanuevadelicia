# La Nueva Delicia website

Bilingual (es/en) marketing site for a Colombian restaurant in Jackson Heights, Queens. Static export, no backend.
Lab-wide rules live in the user's global CLAUDE.md; this file holds project facts only.

## Stack

- Next.js 16 (App Router, `output: "export"`), React 19, TypeScript, Tailwind CSS 4, next-intl (`es` default, `en`).
- Target host: Cloudflare Pages (`public/_headers`, `public/_redirects`). Tests: Vitest, Playwright, Lighthouse CI.
- Node: local 20.20; CI and `.nvmrc` use 22.

## Where things live

- `src/data/restaurant.ts` is the single source of facts (address, phone, hours, happy hour, delivery apps). Never
  hard-code a fact in a component or a message; read it from here.
- `src/data/menu.ts`, `src/data/specials.ts`, `src/data/photos.ts` (generated by `npm run photos`): content.
- `messages/es.json`, `messages/en.json`: UI strings. Client components get strings as props; no `useTranslations`.
- `src/lib/analytics.ts`: typed GA4 events (spec 08). Use `TrackedLink` for every CTA.
- Design tokens are in `src/app/globals.css` and spec 05.

## Commands

See the table in [README.md](README.md). Acceptance is `npm run ci`, `CHROME_PATH=/usr/bin/google-chrome npx lhci
autorun` and `npm run check:ga` (run it alone).

## Working rules

- Talk to the owner in Spanish; code, comments and docs in English.
- Never put `NEXT_PUBLIC_GA_ID` in `.env.local`: it breaks the no-GA e2e tests and sends dev traffic to GA. It is set
  in the Cloudflare Pages production settings.
- `next dev` may write an `AGENTS.md`; delete it, do not commit it.
- Header, mobile nav and bottom bar switch at `lg` (1024px).
